# ITLOG — District 1
A Roblox-inspired 3D playable world prototype built with React, Vite, and Three.js.
## 🎮 About ITLOG
ITLOG is a 3D exploration and mission-based game prototype.
The player can explore a Philippine-inspired urban district, interact with NPCs, complete missions, and earn rewards.
This prototype is designed as the foundation for a larger expandable game world.

🧩 Development Philosophy

ITLOG is being developed as a modular 3D game.

The initial prototype focuses on establishing the core gameplay loop:

SPAWN
   ↓
EXPLORE
   ↓
FIND NPC
   ↓
INTERACT
   ↓
ACCEPT MISSION
   ↓
COMPLETE OBJECTIVE
   ↓
RETURN TO NPC
   ↓
REWARD
   ↓
UNLOCK MORE CONTENT

Future systems should be added without replacing the existing core gameplay.

🎨 Visual Direction

ITLOG uses a stylized blocky 3D visual direction inspired by social sandbox games while maintaining its own identity.

The world is designed around a Philippine-inspired urban environment with:

* Local-style streets
* Small businesses
* Sari-sari stores
* Barangay facilities
* Public plazas
* Street stalls
* Urban neighborhoods
* Local landmarks
* Mission-driven exploration

⚠️ Prototype Status

This is an early playable prototype.

Some systems currently represented in the interface are placeholders and will be implemented progressively.

The current priority is to establish:

PLAYABLE CHARACTER + 3D WORLD + MOBILE CONTROLS + NPC + MISSIONS

before expanding the game into a larger multiplayer world.
